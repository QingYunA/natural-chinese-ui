# 好好说话: 中文界面文案规范

在编写或修改中文软件、网页工具、功能命名、SEO 标题以及界面文案时，按照现代中文的正常习惯来写，简单、务实、直截了当。

---

## 一、大模型写中文界面的常见问题

1. **喜欢加虚词后缀**：把小工具叫成“工坊”、“实验室”、“矩阵”、“魔方”、“空间”、“引擎”。
2. **喜欢凑对仗对联**：例如“人机博弈与双人对弈”、“水墨诗笺与活字排版”。
3. **脱离真实搜索习惯**：用户搜的是“五子棋”、“加空格”，AI 却起名叫“棋枰推演”、“字符疏朗矩阵”。
4. **按钮和提示演戏**：把“换一个”写成“随机赋诗”，把“开始”写成“开启博弈之旅”，报错写成“星球迷路了”。
5. **堆砌大厂空话**：通篇都是“沉浸式”、“赋能”、“一站式”、“极致”，唯独不讲具体是干什么的。
6. **输入框假装深刻**：输入框占位符写“请在此倾注灵感”，而不是给具体输入示例。

---

## 二、核心规则

### 1. 名字要实，去掉多余后缀
是个什么东西就叫什么东西。不要加“工坊”、“实验室”、“矩阵”、“魔方”、“空间”、“引擎”、“神器”、“殿堂”。
- 是工具就叫工具，是计算器就叫计算器。熟知的功能直接叫名字（“在线五子棋”、“番茄钟”）。

### 2. 不要强行凑四字成语和对联
不要为了形式好看，硬把意思相近的词拼在一起凑对仗。
- ❌ `人机博弈与双人对弈工坊`
- ✅ `在线五子棋（支持人机对战与双人同屏）`

### 3. 按真实用户在搜索框里会打的字起名
想一想用户在百度或 Google 里遇到这个问题会搜什么词。
- 用户搜“中英文加空格”，不会搜“字符疏朗矩阵”。
- 标题推荐格式：`[工具名] - [核心功能] | [产品名]`

### 4. 按钮直接写动作，弹窗直接报结果
- 按钮用两到四个字讲清动作：“换一首”、“开始”、“下载图片”、“复制”，别写诗句或戏剧台词。
- 提示信息陈述客观事实：“黑棋获胜（共 24 步）”、“已复制”，别卖萌，别演戏。

### 5. 删掉没有信息量的空话
把“沉浸式”、“赋能”、“一站式”、“闭环”、“极致”删掉，换成具体的数字和功能：
- ❌ “带来极致沉浸式的排版赋能体验”
- ✅ “支持 8 种底色，单文件离线运行，一键导出 PNG”

## 三、常见场景对照表

| 场景 | AI 常见写法（避免） | 正常写法（推荐） | 说明 |
| :--- | :--- | :--- | :--- |
| **棋类游戏** | 人机博弈与双人对弈工坊 | **在线五子棋** | 用户搜的是五子棋，没人搜博弈工坊 |
| **卡片制作** | 水墨诗笺与活字排版工坊 | **古诗词卡片生成器** | 交代清楚核心产出物 |
| **文本排版** | 字符间距规范与疏朗矩阵 | **中英文排版加空格工具** | 解决什么问题就写什么 |
| **时钟页面** | 二十四节气流转罗盘 | **二十四节气时钟** | 去掉罗盘等虚词 |
| **换内容按钮** | 随机赋诗 / 点亮灵感 | **换一首** / **换一个** | 按钮是明确的操作动作 |
| **转换按钮** | 注入灵魂 / 立即升华 | **格式化** / **开始转换** | 交代清楚要做什么 |
| **游戏胜负** | 少侠胜天半子，大局已定！ | **黑棋获胜（共 24 步）** | 交代客观数据，别演戏 |
| **复制提示** | 佳句已然拓印入心 | **已复制到剪贴板** | 清楚交代操作结果 |
| **报错提示** | 哎呀，网络迷路了 | **网络连接失败，请检查后重试** | 说清楚出了什么问题 |
| **输入框提示** | 在此挥洒您的文思与灵感... | **粘贴或输入待处理的内容...** | 给出具体的输入指引 |
| **空列表提示** | 一片未踏足的荒原，等待思想的火种... | **暂无保存的内容**（带新建按钮） | 陈述现状，给下一步操作 |

## 四、词汇对照

- **不要用**：工坊、实验室、矩阵、魔方、空间、引擎、神器、生成仪、美化器、殿堂  
  **建议用**：工具、生成器、转换器、计算器、时钟、配色表，或者直接用功能名本身
- **不要用**：随机赋诗、碰碰运气、点亮灵感、即刻启程、开启之旅、注入灵魂  
  **建议用**：换一个、换一首、开始、格式化、重置、悔棋
- **不要用**：沉浸式、多维赋能、一站式、闭环、极致、纯粹  
  **建议用**：直接删掉，换成支持什么格式、跑得多快等具体参数
- **不要用**：少侠、阁下、胜天半子、佳句拓印、星球迷路  
  **建议用**：黑棋获胜、已复制、网络连接失败

## 五、自检清单

写完文案后，对照这几个问题看一眼：

1. 名字里带了“工坊/矩阵/空间/引擎/魔方”这些词吗？
2. 是不是为了对称硬拼了一句对联？
3. 真实用户遇到问题，会搜这几个字吗？
4. 按钮和提示读起来像不像在念台词或者卖萌？
5. 删掉文案里的形容词后，还剩下具体有用的信息吗？
