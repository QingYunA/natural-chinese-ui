## 📦 一行命令安装（推荐）

通过 `skills` 直接安装到你的编程 Agent（支持 Claude Code, Cursor, Codex, Pi 等全部 70+ Agent，无需手动克隆）：

```bash
# 安装到当前项目工作区
npx skills add QingYunA/natural-chinese-ui

# 或者全局安装到本机所有 Agent
npx skills add QingYunA/natural-chinese-ui -g
```

<details>
<summary><strong>手动配置与其他工具接入方式</strong></summary>

### 1. Cursor / Windsurf
把仓库中的 [`rules/natural-chinese-ui.mdc`](./rules/natural-chinese-ui.mdc) 拷贝到你的项目 `.cursor/rules/` 目录下即可。

### 2. Antigravity / Google Agentic IDE
在项目根目录运行：
```bash
mkdir -p .agents/skills/natural-chinese-ui
curl -sSL https://raw.githubusercontent.com/QingYunA/natural-chinese-ui/main/SKILL.md -o .agents/skills/natural-chinese-ui/SKILL.md
```

### 3. ChatGPT / Claude / DeepSeek 网页端
复制 [`prompts/system-prompt.md`](./prompts/system-prompt.md) 的纯文本内容，直接贴进 Custom Instructions 或对话首条即可。

</details>

## 💡 为什么做这个规范？

只要让大模型写个中文小工具或者前端网页，最让人头疼的就是文案：

- 一个 50 行 JS 的在线五子棋，它非要起名叫“**人机博弈与双人对弈工坊**”；
- 一个生成诗词图片的单页，它非要叫“**水墨诗笺与活字排版工坊**”；
- 一个给中英文字符加空格的小脚本，它能给整成“**汉字与西文字符疏朗美化矩阵**”。

界面的微文案就更离谱了：
- 换内容的按钮不叫“换一首”，非要叫“**随机赋诗**”或“**点亮灵感**”；
- 棋局结束弹窗不报谁赢了几步，非要演戏写“**少侠好棋艺，运筹帷幄之中，已成胜局！**”；
- 网络断了不报原因，非要卖萌写“**哎呀，星球迷路了，信号在时空长河中失联啦~**”；
- 表单输入框的占位符动不动就“**请在此处倾注您的灵感与宏图**”……

**结果就是：正常用户看不懂，搜索引擎搜不到，整个产品一股廉价的中二塑料味。**

这个规范不搞花架子，就解决这一件事：**把大模型吐出来的这些古怪中文，改回正常中国人在日常生活和工业软件里真正会说、会查、会点的人话。**

| **棋类网页** | 人机博弈与双人对弈工坊 | **在线五子棋** | 没人会去搜“博弈工坊”，直接叫五子棋 |
| **卡片工具** | 水墨诗笺与活字排版工坊 | **古诗词卡片生成器** | 核心产物就是卡片，说清楚是干什么的 |
| **排版脚本** | 字符间距规范与呼吸感疏朗矩阵 | **中英文排版加空格工具** | 用户搜的是“加空格”，不是“疏朗矩阵” |
| **时钟页面** | 二十四节气天干地支流转罗盘 | **二十四节气时钟** | 本质是时钟，去掉中二修辞 |
| **网页标题** | 水墨诗笺工坊 - 传承华夏风雅，赋能指尖排版 | **古诗词卡片生成器 - 在线排版并导出高清卡片图片** | 符合搜索引擎真实检索心智 |
| **随机按钮** | 随机赋诗 / 碰碰运气 / 点亮灵感 | **换一首** / **换一个** | 按钮是明确的操作指令，不是文学独白 |
| **转换按钮** | 一键升华美化 / 注入灵魂 | **格式化** / **开始转换** | 直截了当，交代清楚要干嘛 |
| **结算弹窗** | 少侠胜天半子！神机妙算，大局已定！ | **黑棋获胜（共 24 步）** | 交代客观数据，别演戏 |
| **复制提示** | 佳句已然拓印入心，随时准备绽放！ | **已复制到剪贴板** | 冷静陈述操作结果 |
| **报错提示** | 哎呀，网络在时空长河中迷路啦~ | **网络连接失败，请检查网络后重试** | 告诉用户出了什么事，怎么解决 |
| **输入框占位**| 在此处挥洒您的文思与灵感... | **粘贴或输入文本内容...** | 给出真实输入示例，不做哲学提问 |
| **空数据状态**| 一片未踏足的荒原，等待思想的火种... | **暂无保存的卡片**（带“新建卡片”按钮） | 陈述现状，给用户明确的下一步操作 |

## 🎯 五条硬规则

### 1. 别加“工坊”“矩阵”这种虚浮后缀，是什么就叫什么
真正的现代软件讲究诚实、克制与实用。
- **禁止出现的后缀**：`工坊`、`实验室 (Lab)`、`工作台`、`矩阵`、`魔方`、`空间`、`引擎`、`神器`、`生成仪`、`美化器`、`殿堂`。
- **改法**：是工具就叫工具，是计算器就叫计算器，是转换器就叫转换器。像“在线五子棋”、“番茄钟”、“在线打字练习”这种大家本身就明白的功能，连后缀都不要加，直接叫名字。

### 2. 别为了对称硬凑四字成语和八字对联
不要强行把两个近义动词拼在一起凑对仗（比如把人机对战和双人同屏拼成“人机博弈与双人对弈”）。
- 现代产品文案追求短句利落。主功能直接说明，次要功能用破折号或者括号平实交代：
  - ❌ `水墨诗笺与活字排版工坊`
  - ✅ `古诗词卡片生成器 - 在线排版与图片导出`

### 3. 按真实用户在搜索框里会打的字来起名
起名字前问自己一句：**“一个普通人在网上遇到这个问题，真的会在百度或谷歌里敲这几个字吗？”**
- 用户要给文章中英文混排加空格，他搜的一定是“中英文加空格”，绝对不会搜“文字呼吸感疏朗矩阵”。
- **标题推荐写法**：`[核心工具名] - [核心卖点或适用场景] | [产品或品牌名]`

### 4. 按钮直接写动作，弹窗直接报结果，别演戏
- **按钮** 是用户给软件下达的动作指令，用两到四个字写清楚动作即可（`开始`、`换一首`、`导出 PNG`、`复制`），不要写成戏剧台词。
- **反馈与提示** 必须客观中立，交代真实数据和状态（`黑棋获胜（共 24 步）`），不要谄媚，更不要搞古风戏精。

### 5. 删掉“赋能”“沉浸式”这种大厂空话，直接说参数
把所有删掉之后不影响理解的空洞形容词全删了：`沉浸式`、`多维赋能`、`一站式`、`闭环`、`极致`、`纯粹`、`重磅打造`。
- 换成能感知的具体参数、格式与数字：
  - ❌ “为您带来极致沉浸式的排版美学赋能体验”
  - ✅ “内置 8 款宣纸底色，单文件离线运行，一键导出高清 PNG”

## 📕 高频违禁词与人话替换表

| 类别 | ❌ 严禁使用的大模型恶习词 | ✅ 换成真实好懂的人话 |
| :--- | :--- | :--- |
| **虚浮后缀** | 工坊、实验室、矩阵、魔方、空间、引擎、神器、生成仪、美化器、工作台、殿堂 | 工具、生成器、转换器、计算器、时钟、配色表（或直接用功能名本身） |
| **戏精动词** | 随机赋诗、碰碰运气、点亮灵感、即刻启程、开启之旅、注入灵魂、拂去尘埃 | 换一首、随机换一个、开始、立即排版、重置、悔棋、撤销 |
| **公关废话** | 沉浸式、多维赋能、一站式、闭环、极致、纯粹、颠覆式、全新定义 | *(直接删掉，换成“单文件运行”、“响应 < 100ms”等具体技术参数)* |
| **浮夸提示** | 少侠、阁下、胜天半子、佳句拓印、墨宝封存、迷失在时空长河中、荒原 | 黑棋获胜、已复制、图片已导出、网络连接失败、暂无数据 |
| **强凑对仗** | 人机博弈与双人对弈、水墨诗笺与活字排版、天干地支与四时更迭 | 在线五子棋、古诗词卡片生成器、二十四节气时钟、中英文加空格工具 |

## 🔍 自检清单

在写完或者重构完中文产品的名字、标题或界面文案后，拿这 5 个问题过一遍。**只要有任意一个是“是”，立刻改掉：**

1. ❓ 名字里带了“工坊/实验室/矩阵/引擎/魔方/空间”这种大词吗？
2. ❓ 是不是为了对称硬拼了一句像“XX博弈与XX对弈”的对联？
3. ❓ 真实用户遇到这问题，会在搜索框里敲这些字吗？
4. ❓ 按钮或弹窗读起来像不像古装剧念台词、文青独白或者卖萌？
5. ❓ 把文案里的“沉浸式/极致/一站式/赋能”删掉后，整句话还剩下有用的信息吗？
