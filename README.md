## 💡 为什么需要本规范？

几乎所有用 AI 写过前端网页、独立开发工具或小程序的中国开发者，都受过这种折磨：

只要让大模型起个名字，50 行 JavaScript 的小工具瞬间变成了：
- ❌ **“水墨诗笺与活字排版工坊”**（其实就是做个诗词卡片并导出图片）
- ❌ **“人机博弈与双人对弈空间”**（其实就是个在线五子棋）
- ❌ **“字符呼吸感与间距疏朗矩阵”**（其实就是中文英文中间自动加空格）

**更灾难的是微文案与按钮：**
- 换内容的按钮非要叫 **“随机赋诗”** 或 **“点亮灵感”**；
- 棋局结束弹窗非要演戏写 **“少侠胜天半子，神机妙算！”**；
- 报错断网非要卖萌写 **“哎呀，星球迷路了，信号在时空长河中失联啦~”**；
- 输入框 Placeholder 动辄 **“在此倾注您的灵感与宏图”**……

> **结果就是：真实用户看不懂、搜索引擎零收录、页面充满廉价而中二的 AI 塑料味。**

`Natural Chinese UI` 是一套严苛、克制、面向现代工业级软件的中文 UI/微文案规范。它的核心目标是：**消灭大模型的表演型人格，让中文产品说人话。**

## 🎯 核心黄金准则

### 1. 直陈功能事实，消灭假大空后缀
- **禁止词库**：`工坊`、`实验室 (Lab)`、`工作台`、`矩阵`、`魔方`、`空间`、`引擎`、`神器`、`生成仪`、`美化器`、`殿堂`。
- **正向规范**：根据实际形态采用克制的名词：`工具`、`生成器`、`转换器`、`计算器`、`时钟`、`配色表`；若功能本身足够知名，**直接叫功能名**（如“五子棋”、“番茄钟”）。

### 2. 打破伪古风，消灭机械式对偶
- 拒绝为了对称强拼八字骈体对联（如“人机博弈与双人对弈”本质就是同一件事的两种模式）。
- 主功能单刀直入，次级特性用短句或括号平实交代：
  - ❌ `人机博弈与双人对弈工坊`
  - ✅ `在线五子棋 - 支持人机对战与双人同屏`

### 3. 锚定人类真实搜索心智（SEO 优先）
- 命名必须通过拷问：**“真实人类在遇到这个问题时，会在百度或 Google 里敲入这几个字吗？”**
- **标准标题公式**：
  `[核心工具名/功能] - [核心卖点/适用场景] | [产品品牌]`
  - ❌ `水墨诗笺与活字排版工坊 - 传承华夏风雅，赋能指尖东方美学排版艺术`
  - ✅ `古诗词卡片生成器 - 在线制作精美诗词卡片与排版导出`

### 4. 界面微文案动词先行，客观中立
- **按钮（CTA）** 是用户给机器下达的指令，必须是 2~4 个字的确定性动词（`开始`、`换一首`、`导出图片`、`复制`），绝不是文学独白。
- **反馈与状态** 是客观数据，绝不演戏、绝不谄媚（`黑棋获胜`，不是 `少侠胜天半子`）。

### 5. 全域消灭公关黑话与形容词轰炸
- 坚决删除：`沉浸式`、`多维赋能`、`一站式`、`闭环`、`极致`、`纯粹`、`重磅打造`。
- 用**具体参数与事实**说话：
  - ❌ “为您带来极致沉浸式的现代诗词排版与美学赋能体验”
  - ✅ “支持 8 种宣纸底色与排版样式，单文件离线运行，一键导出高清 PNG 图片”

## 📕 违禁词与替换速查表

在代码审查或文案重构中，凡是命中左列词汇，一律按右列建议替换：

| 违禁类别 | ❌ 严禁使用的 AI 恶习词 | ✅ 建议替换的自然人话 |
| :--- | :--- | :--- |
| **虚浮后缀** | 工坊、实验室、矩阵、魔方、空间、引擎、神器、生成仪、美化器、工作台、殿堂 | 工具、生成器、转换器、计算器、时钟、配色表（或直接用功能名） |
| **剧场动词** | 随机赋诗、碰碰运气、点亮灵感、即刻启程、开启之旅、注入灵魂、拂去尘埃 | 换一首、随机生成、开始、创建、立即排版、重置、悔棋、撤销 |
| **公关空话** | 沉浸式、多维赋能、一站式、闭环、极致、纯粹、颠覆式、全新定义 | *(直接删除，换成“单文件运行”、“响应 < 100ms”等具体技术参数)* |
| **戏精反馈** | 少侠、阁下、胜天半子、佳句拓印、墨宝封存、迷失在时空长河中、荒原 | 黑棋获胜、已复制、图片已导出、网络连接失败、暂无数据 |
| **伪文青对偶** | 人机博弈与双人对弈、水墨诗笺与活字排版、天干地支与四时更迭 | 在线五子棋、古诗词卡片生成器、农历节气时钟、中英文加空格工具 |

## 🚀 接入与使用方式

你可以非常方便地将本规范集成到你喜爱的任何 AI 编程工具中：

### 1. Claude Code
直接安装为 Claude Code Skill：
```bash
# 进入你的项目根目录
mkdir -p .claude/skills/natural-chinese-ui
curl -o .claude/skills/natural-chinese-ui/SKILL.md https://raw.githubusercontent.com/QingYunA/natural-chinese-ui/main/SKILL.md
```

### 2. Antigravity / Google Agentic IDE
作为 Agent Skill 载入：
```bash
mkdir -p .agents/skills/natural-chinese-ui
curl -o .agents/skills/natural-chinese-ui/SKILL.md https://raw.githubusercontent.com/QingYunA/natural-chinese-ui/main/SKILL.md
```

### 3. Cursor / Windsurf
复制 [rules/natural-chinese-ui.mdc](./rules/natural-chinese-ui.mdc) 到你的项目 `.cursor/rules/` 或 `.windsurfrules`。

### 4. ChatGPT / Claude / DeepSeek 网页端
直接将 [prompts/system-prompt.md](./prompts/system-prompt.md) 中的内容复制进自定义指令（Custom Instructions）或 System Prompt 即可。

## 🔍 自检五问法（Sanity Check）

在提交任何中文产品名称、SEO 标题或 UI 文案前，逐字默读并回答以下 5 个问题。**若有任何一项答案为“是”，立刻打回重写：**

1. ❓ **是否有“工坊/实验室/矩阵/引擎/生成仪/空间/魔方”等虚浮后缀？**
2. ❓ **是否存在强行对称的八字骈体对联？**（如“XX博弈与XX对弈”）
3. ❓ **真实用户在 Google / 百度上遇到这个问题，会搜这个词吗？**
4. ❓ **按钮、报错或提示语读起来像不像武侠台词、文青独白或卖萌戏精？**
5. ❓ **把所有形容词（沉浸式/极致/一站式/华美/赋能）删掉后，这句话还能剩下具体信息吗？**
